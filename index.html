About Me

I'm a backend-focused Software Engineer with 7 years of professional experience building and maintaining web applications, primarily using Node.js, JavaScript, and Express.

I started my career working mostly on frontend development with JavaScript and Webpack. Over the past few years, I have shifted my focus toward backend engineering, building APIs in JavaScript and TypeScript, working with relational and non-relational databases, implementing Redis caching, writing automated tests, using Docker, and automating deployment workflows.

I currently also work as a Tech Lead while remaining hands-on with development. My responsibilities include code reviews, supporting other developers, contributing to sprint planning, making technical decisions, and investigating and resolving production issues.

I'm particularly interested in backend engineering, API development, software architecture, performance, reliability, and the practical use of AI in software development.
